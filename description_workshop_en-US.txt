A localization enhancement mod for [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2992680615]Biome Titles[/url].

Biome Titles uses manually curated entries for biome names.
This mod hooks into the title resolution to automate that process — reading translated names directly from each mod's own localization files.

[h2]Features[/h2]
[list]
[*]Biome Name Localization — Automatically loads each mod's translation files to display localized biome names
[*]Source Mod Priority — Prioritizes the biome's own mod localization (supports translation mods); values identical to the source mod's en-US original are treated as untranslated, so the search continues in BTitles or this patch's translations
[*]Extra Translations — Provides missing Biome Titles translations (e.g. Aether)
[*]Auto Scan — Automatically discovers unregistered ModBiomes and adds them to Biome Titles, skips placeholder biomes that don't override the detection method; scan summary shows pending-color count
[*]Scan List — Control which biomes the scan covers with a single list: use it as a blacklist (listed biomes are skipped) or a whitelist (only listed biomes are scanned); accepts internal keys, short names, or the on-screen title
[*]Auto Styling — Assigns title colors to the biomes the scan covers: defaults to "background first" (uses the mod-defined BackgroundColor; falls back to sampling a representative color — the average of valid pixels — from the icon when the background color is missing or near-white); also offers background color only, icon sampling, or a fixed color
[*]Per-Biome Colors — Assign a color to a specific biome by the title name shown on screen; takes priority over the automatic color source
[/list]

[h2]Name Resolution Order[/h2]
The mod looks up biome names in the following priority order. Once a translation is found, the mod checks for a custom override; otherwise it continues down the chain:
[list=1]
[*]Source Mod Localization — Reads from the biome's own mod localization files
[*]Biome Titles Localization — Uses Biome Titles' manually curated translations
[*]Extra Translations — Translations provided by this patch (e.g. Aether)
[*]User Custom Override — After any of the above hits, checks if a custom name is set in config (overrides if found)
[*]Original Name — Falls back to the original English name if nothing else matches
[/list]

[h2]Configuration[/h2]
[list]
[*]Scan for new biomes — Auto-discover and register unregistered ModBiomes into the dictionary (takes effect immediately after saving)
[*]Only biomes not added by "Biome Titles" — Skip biomes Biome Titles already has; no overwrite, no recolor, and their display is left exactly as Biome Titles shows it; changing it triggers an immediate rescan
[*]Biome blacklist/whitelist mode — Disabled / Blacklist / Whitelist, decides how the list is used
[*]List — Read as a blacklist or whitelist depending on the mode; changes trigger an immediate rescan
[*]Color Scheme — Assign title colors to the biomes the scan covers; also the master switch for per-biome title colors
[*]Color Source / Fixed Title Color — Pick the coloring strategy, or set the color used by the "Fixed" strategy
[*]Per-biome title colors — Assign a color to a specific biome by the title name shown on screen; takes priority over Color Source
[*]Debug logs — Output debug info to client.log for troubleshooting
[/list]

[h2]Compatibility[/h2]
[list]
[*]Client-side only — no impact on multiplayer
[*]Uses MonoMod hooks — fully compatible with Biome Titles
[*]Auto scan uses tModLoader native reflection — no specific mod dependency
[/list]
