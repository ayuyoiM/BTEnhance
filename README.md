# Biome Titles Enhance

[![Steam](https://img.shields.io/badge/%E5%88%9B%E6%84%8F%E5%B7%A5%E5%9D%8A-Steam?style=flat-square&logo=Steam&label=Steam&color=%23000000)](https://steamcommunity.com/sharedfiles/filedetails/?id=3758079429)
[![Steam Update Date](https://img.shields.io/steam/update-date/3758079429?style=flat-square&label=工坊更新时间)](https://steamcommunity.com/sharedfiles/filedetails/changelog/3758079429)

一个为 [Biome Titles（生物群系名称）](https://steamcommunity.com/sharedfiles/filedetails/?id=2992680615) 提供本地化与配色增强的 tModLoader 模组。

Biome Titles 使用手动维护的方式收录群系名称。
本补丁通过挂钩标题解析流程，用自动化取代手动维护——直接从各模组的本地化文件中读取已翻译的名称。

## 功能总览

### 群系名称本地化（核心）

按以下优先级依次查找群系名称，命中即进入自定义覆盖判断，否则继续向下查找：

- 源模组本地化 → 优先读取群系所属模组自身的本地化文件
    （支持汉化模组；读取结果若与该模组 en-US 原文一致，视为「未翻译」，跳过该来源以避免在非英文界面下显示英文。
    若该模组没有 en-US 资产、或该键只由 BTitles 在运行时注册，则退回纯 ASCII 判定，与任何启发式方案一样存在边界情况）
- Biome Titles 本地化 → 使用 Biome Titles 手动维护的本地化
- 补充翻译 → 本模组提供 Biome Titles 缺失的原版翻译（`Aether → 以太`）
- 用户自定义覆盖 → 上述任一命中后，再检查模组配置中是否有自定义名称（如有则覆盖）
- 若均未命中，回退显示原始名称（即英文）

> 卸载（或关闭扫描）时，模组通过主线程跳转撤销本次会话写入的内容：移除新增条目、用扫描前快照还原被改写的已有条目、移除插入的检测函数。主线程跳转失败时记入日志并保留现状，不会中断卸载流程。

### 自动扫描与注册

> 默认开启，可在配置中关闭。

扫描所有已加载模组中的模组群系，自动完成：

- 已收录群系 — 更新标题和本地化作用域，不动颜色/图标（以内置为主）；
    开启「仅补漏群系」后完全跳过，这些群系也不会进入本模组的检测函数，显示效果保持 Biome Titles 原样
- 未收录群系 — 自动注册到 Biome Titles 字典，并添加检测函数
- 占位群系跳过 — 跳过未重写 `IsBiomeActive` 的占位群系
- 独立检测函数 — 插入到检测列表最前方，确保优先匹配

### 扫描名单（群系黑白名单）

> 默认关闭。名单只影响扫描，管不到 Biome Titles 自己收录的群系。

一张列表 + 一个模式开关，决定哪些群系参与扫描：

- 群系黑白名单模式「关闭」 — 名单不生效，表里的内容原样留着
- 群系黑白名单模式「黑名单」 — 名单里的群系不扫描
- 群系黑白名单模式「白名单」 — 只扫描名单里的群系；名单为空时全部扫描
- 三种写法都认 — 模组内部键（`模组名.群系名`）、群系短名、屏幕上显示的标题名；忽略大小写与首尾空白
- 只跳过不报错 — 名字拼错就是没命中，不会中断扫描
- 改动即时生效 — 名单或模式改完保存后自动「先撤再扫」，不用重载模组

### 自动配色

> 默认开启，可在配置中关闭。颜色来源默认为「背景色」，可改为「图标采样」「固定颜色」或「背景色优先」。

按所选颜色策略为扫描新增的群系设置标题颜色：

- 颜色来源「背景色」（默认） — 只使用模组定义的背景色；没有背景色时保持白色，不做图标采样；
- 颜色来源「图标采样」 — 总是从群系图标采样代表性颜色；
- 颜色来源「固定颜色」 — 使用配置中指定的颜色；
- 颜色来源「背景色优先」 — 优先用背景色；没有背景色或背景色是白色时，回落到图标采样；
- 标题描边色不由本模组改动，沿用 Biome Titles 默认值

> 图标采样在回到主线程后进行（扫描在后台线程）。
>
> 取的是有效像素的平均色，而不是面积最大的那个色块：半透明、接近纯黑纯白、以及三通道极差过小的灰调像素都先剔除，再对剩下的求平均，最后把饱和度和亮度下限往上推一点（色相不动）。
>
> 这样渐变色图标不会只取到一块纯色，也不会被大块灰底拉浑、被暗部拖暗。
>
> 采样到时纹理已被释放会先尝试重载，读取失败或剔除后没有有效像素时回退灰色（图标尚未加载完成的条目会留在待补色队列里，等图标到位再采样；扫描时就没有图标资产的群系不会入队）

### 逐群系配色

> 表默认为空，填一条才生效；整档受「配色」开关控制。

配置中可维护一张「标题文字 → 颜色」的对照表：

- 匹配的是屏幕上实际显示的标题名；填你看见的那个名字即可
- 命中时覆盖「颜色来源」的策略色；一条都匹配不上时按策略色处理
- 匹配精确且区分大小写，名字对不上时宁可不生效，也不会猜错群系
- 表格改动保存后即时生效：保存时会把当前标题重算一次，不必等走出再走回群系

### 补充翻译

在本地化文件中通过 `ExtraTitles.{作用域}.{键名}` 补充 Biome Titles 缺失的原版翻译

## 配置说明

在游戏内模组配置中找到「Biome Titles Enhance（生物群系标题增强）」即可调节：

| 配置项 | 默认值 | |
| --- | --- | --- |
| 扫描新群系 | 开 | 启用后自动扫描未收录群系并注册到字典；关闭时自动移除新注册的群系、还原被改写的已有条目（配置保存后即时生效，重载模组时同样会撤净） |
| 仅补漏群系 | 开 | 开启后扫描不触碰 BTitles 已注册的群系：不覆写标题、不配色、不做快照（配置保存后立即先撤再扫，即时生效） |
| 群系黑白名单模式 | 关 | `关闭`（名单不生效）<p> `黑名单`（名单里的群系不扫描）<p> `白名单`（只扫描名单里的群系，名单为空时全部扫描） |
| 名单 | 空 | 按「群系黑白名单模式」解释成黑名单或白名单；三种写法都认：内部键（`模组名.群系名`）、群系短名、屏幕显示名（配置保存后立即先撤再扫，即时生效） |
| 配色 | 开 | 为扫描涉及的群系设置标题颜色：策略变更时，已扫描条目会在回到主线程后按新策略重新配色（配置保存后即时生效）。关闭时逐群系标题颜色一并失效 |
| 颜色来源 | 背景色 | `背景色`（只用群系背景色，没有则白色）<p> `背景色优先`（背景色优先，没有背景色或背景色是白色时图标采样） <p> `图标采样`（总是从图标采代表性颜色）<p> `固定颜色`（总是使用配置中的固定颜色） |
| 固定标题颜色 | 白 | 仅当颜色来源为「固定颜色」时生效 |
| 逐群系标题颜色 | 空 | 「标题文字 → 颜色」对照表，按屏幕上显示的标题名匹配，命中优先于「颜色来源」 |
| 调试日志 | 关 | 输出调试信息到 `client.log`，排查问题时可开启（含逐条跳过的群系） |

## 兼容性

- 本模组为纯客户端模组，不影响联机
- 使用 `MonoMod.RuntimeDetour.Hook` 挂钩 `GetActualTitleName`，与原模组兼容良好
- 自动扫描功能通过 tModLoader 原生反射和 `ModBiome.IsBiomeActive` 检测，不依赖特定模组
